    FAQ

    Questions,
    answered.

    Is it really free?

    Yes. The browser is free. The AI features use your own ChatGPT plan, an OpenAI API key, or a model running on your Mac.

    Can I bring my Arc or Chrome setup?

    Yes. During onboarding or in Settings › Import, bring Arc Spaces, colours, nested folders, favourites, pinned and open tabs, history and saved passwords. Arc password import needs macOS Keychain authorization. Chrome import is available too.

    Do Chrome extensions work?

    On macOS, yes: extensions install straight from the Chrome Web Store. iPhone extension support is planned.

    What can the agent do without asking?

    Read, scroll, click, type into ordinary fields, navigate and switch tabs. Submitting, sending, buying, signing in, account changes, uploads, downloads and secrets all wait for your approval.

    Which Macs are supported?

    The current download is for Apple silicon Macs. Check for a newer download before use.

    Is there an iPhone version?

    A native iPhone version is in development, with Spaces, tab cards, private browsing and on-device Algorithm Diet. The images above are from the app. Desktop agent control and meeting features aren’t available on iPhone yet.

    Can I walk through onboarding again?

    Yes. Open Settings › General › Replay onboarding. It keeps your existing tabs, Spaces, passwords and other profile data.

    Is there a Windows version?

    Not yet. macOS first.
