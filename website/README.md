# Marketing site

This static product demo needs no build step. Serve the repository root for local preview
(e.g. `python3 -m http.server 8000`), then open `/website/` so the build guide links resolve.
The illustrations are original SVGs with example data. The interactive scenes are simulations.
The demo uses local assets and system fonts. It sets no cookies, stores no visitor ID,
and contains no analytics or admin dashboard. The Mac button links to the separately
hosted Apple silicon installer; this repository does not publish the installer.
